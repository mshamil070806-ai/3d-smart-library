# 3D സ്മാർട്ട് ലൈബ്രറി (Smart 3D Library)

ബ്ലെൻഡർ മോഡൽ ഉപയോഗിച്ച് നിർമ്മിച്ച അത്യാധുനിക 3D ഇന്ററാക്ടീവ് ലൈബ്രറി വെബ്സൈറ്റ് (Three.js, WebGL & Python).

---

### ✨ പ്രധാന സവിശേഷതകൾ (Key Features)

1. **യഥാർത്ഥ 3D ലൈബ്രറി അന്തരീക്ഷം:**
   - Blender ഫയലിലെ 40 ഷെൽഫുകളും വാതിലുകളും മുറിയും വെബ്ബിൽ അതിവേഗം ലോഡ് ആകുന്ന ഒപ്റ്റിമൈസ് ചെയ്ത `.glb` ഫോർമാറ്റിലേക്ക് മാറ്റി Three.js വഴി റെൻഡർ ചെയ്യുന്നു.
   - പ്രവേശന കവാടത്തിൽ നിന്നുള്ള സ്വാഭാവിക ക്യാമറ കാഴ്ചയും മൗസ് ഓർബിറ്റ് നാവിഗേഷനും.

2. **അടുക്കിവെക്കുന്ന പ്രത്യേക ക്രമം (Middle → Down → Up):**
   - ഓരോ ഷെൽഫിലെയും രണ്ട് തിരശ്ചീന മെറ്റൽ കമ്പികളോട് തൊട്ടുനിൽക്കുന്ന തരത്തിൽ പുസ്തകങ്ങൾ നിരയായി അടുക്കുന്നു.
   - പുസ്തകങ്ങൾ ആദ്യം **നടുവിലെ റാക്കിലാണ് (Rack 3)** നിറയുന്നത്. നടുക്ക് നിറഞ്ഞാൽ താഴേക്ക് (**Rack 2 → Rack 1**), തുടർന്ന് മുകളിലേക്ക് (**Rack 4 → Rack 5**) നിറയുന്നു.

3. **സ്ഥാനം കസ്റ്റമൈസ് ചെയ്യാനുള്ള സൗകര്യം (Custom Placement per Book):**
   - പുതിയ ബുക്ക് ചേർക്കുമ്പോഴോ നിലവിലുള്ള ബുക്കുകൾക്കോ ഇഷ്ടമുള്ള റാക്ക് (Rack 1-5), ബേ (Bay 1/2), സ്ലോട്ട് (Slot 1-15) എന്നിവ തിരഞ്ഞെടുക്കാം.
   - സ്ഥാനം മാറ്റിയാൽ ക്യാമറ അങ്ങോട്ട് പറന്നെത്തി ആ പുസ്തകം ഉയർത്തിക്കാട്ടുന്നു.

4. **ഷെൽഫുകളും കാറ്റഗറികളും മാനേജ് ചെയ്യാനുള്ള സൗകര്യം (Shelf & Category Management):**
   - ഏത് ഷെൽഫ് റോയ്ക്കും ഇഷ്ടമുള്ള കാറ്റഗറി അസൈൻ ചെയ്യാം.
   - പുതിയ കാറ്റഗറികൾ (പേര്, കളർ തീം, ഷെൽഫ് റോ) നിർമ്മിക്കാം.
   - 3D-യിൽ ഓരോ ഷെൽഫിന്റെയും മുകളിൽ പ്രകാശിക്കുന്ന 3D ഫ്ലോട്ടിംഗ് ബോർഡുകൾ (Illuminated 3D Signs).
   - 3D-യിൽ ഷെൽഫിൽ നേരിട്ട് ക്ലിക്ക് ചെയ്തും കാറ്റഗറി മാറ്റാം.

5. **സ്മാർട്ട് സെർച്ച് സിസ്റ്റം (Instant Live Search):**
   - ബുക്കിന്റെ പേര് (മലയാളത്തിലോ ഇംഗ്ലീഷിലോ), ഓതറുടെ പേര്, ബാർകോഡ് നമ്പർ, കാറ്റഗറി എന്നിവ വെച്ച് തത്സമയം സെർച്ച് ചെയ്യാം.

6. **സിനിമാറ്റിക് ക്യാമറ ഫ്ലൈ-ത്രൂ & ബുക്ക് ലിഫ്റ്റ് (Camera Walkthrough & Book Floating):**
   - സെർച്ചിൽ നിന്ന് അല്ലെങ്കിൽ നേരിട്ട് ക്ലിക്ക് ചെയ്താൽ:
     - ക്യാമറ ലൈബ്രറി ഇടനാഴിയിലൂടെ സുഗമമായി നീങ്ങി ആ ഷെൽഫിന്റെ മുന്നിൽ ഫോക്കസ് ചെയ്യുന്നു.
     - നിർദ്ദിഷ്ട ബുക്ക് അയൽപക്ക ബുക്കുകളുടെ ഇടയിൽ നിന്ന് മുന്നോട്ട് തെന്നിമാറി, മുകളിലേക്ക് ഉയർന്ന്, ഉപയോക്താവിന് നേരെ തിരിഞ്ഞു നിൽക്കുന്നു.
     - "തിരികെ വെക്കുക (Put Back)" ക്ലിക്ക് ചെയ്താൽ ബുക്ക് സുഗമമായി തിരികെ ഷെൽഫിലെ അതിന്റെ സ്ലോട്ടിലേക്ക് കയറിപ്പോകുന്നു.

---

### 🚀 എങ്ങനെ പ്രവർത്തിപ്പിക്കാം (How to Run)

1. ഫോൾഡറിലുള്ള **`run_library.bat`** ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക.
   - അല്ലെങ്കിൽ ടെർമിനലിൽ:
     ```bash
     python server.py
     ```
2. ബ്രൗസറിൽ **`http://localhost:5050`** തുറക്കുക.

---

### 📁 ഫയൽ ഘടന (File Structure)

- **`library.glb`**: Blender-ൽ നിന്ന് ഒപ്റ്റിമൈസ് ചെയ്ത 3D ലൈബ്രറി മോഡൽ (8.7 MB).
- **`library_shelves_updated.blend`**: 40 ഷെൽഫുകൾ അടങ്ങിയ സമ്പൂർണ്ണ ബ്ലെൻഡർ സോഴ്സ് ഫയൽ.
- **`library_layout.json`**: ഓരോ കാറ്റഗറിയുടെയും ഷെൽഫ് കോർഡിനേറ്റുകളും റാക്ക് ലെവലുകളും.
- **`books.json`**: ലൈബ്രറിയിലെ പുസ്തകങ്ങളുടെ ഡാറ്റാബേസ്.
- **`app.js`**: Three.js, GSAP ക്യാമറ ഫ്ലൈറ്റ്, പ്രൊസീജറൽ ബുക്ക് ടെക്സ്ചറുകൾ, ഷെൽഫ് & കാറ്റഗറി മാനേജ്‌മെന്റ്.
- **`styles.css`**: ഡാർക്ക്-മോഡ് ഗ്ലാസ്മോർഫിക് സ്റ്റൈലിംഗ്.
- **`index.html`**: പ്രധാന വെബ് ഇന്റർഫേസും മോഡലുകളും.
- **`server.py`**: പുസ്തകങ്ങളും കാറ്റഗറികളും മാനേജ് ചെയ്യുന്ന Python REST API ബാക്കെൻഡ്.
