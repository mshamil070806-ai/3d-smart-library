# 3D സ്മാർട്ട് ലൈബ്രറി (Smart 3D Library)

നിങ്ങൾ നൽകിയ ബ്ലെൻഡർ മോഡൽ (`library_shelves.blend`) ഉപയോഗിച്ച് നിർമ്മിച്ച അത്യാധുനിക 3D ഇന്ററാക്ടീവ് ലൈബ്രറി വെബ്സൈറ്റ്.

---

### ✨ പ്രധാന സവിശേഷതകൾ (Key Features)

1. **യഥാർത്ഥ 3D ലൈബ്രറി അന്തരീക്ഷം:**
   - നൽകിയ Blender ഫയലിലെ വാതിലും ഷെൽഫുകളും വെബ്ബിൽ അതിവേഗം ലോഡ് ആകുന്ന `.glb` ഫോർമാറ്റിലേക്ക് മാറ്റി Three.js വഴി റെൻഡർ ചെയ്തിരിക്കുന്നു.
   - വാതിലിന്റെ മുന്നിൽ നിന്നുള്ള സ്വാഭാവിക ക്യാമറ കാഴ്ച.

2. **അഡ്മിൻ പാനലും ഡൈനാമിക് 3D ബുക്കുകളും (Dynamic Procedural Generation):**
   - അഡ്മിൻ പാനലിൽ നിന്ന് ബുക്കിന്റെ പേര്, ഓതർ, ബാർകോഡ് നമ്പർ, കാറ്റഗറി, കവർ കളർ എന്നിവ നൽകി "ചേർക്കുക" എന്ന് ക്ലിക്ക് ചെയ്യുമ്പോൾ തന്നെ:
     - 3D ഷെൽഫിൽ തനിയെ ബുക്ക് രൂപപ്പെടുന്നു.
     - ഒരേ വലിപ്പമുള്ള ബുക്കുകൾ നിരയായി ഷെൽഫിൽ അണിനിരക്കുന്നു. ഒരു റാക്ക് ഫുൾ ആകുമ്പോൾ അടുത്ത റാക്കിലേക്ക് ഓട്ടോമാറ്റിക് ആയി നിറയുന്നു.
     - ഓരോ ബുക്കിന്റെയും സ്പൈനിലും കവറിലും പേരും ഓതറുടെ പേരും ബാർകോഡും പ്രിന്റ് ചെയ്യപ്പെടുന്നു.

3. **സ്മാർട്ട് സെർച്ച് സിസ്റ്റം (Instant Live Search):**
   - ബുക്കിന്റെ പേര് (മലയാളത്തിലോ ഇംഗ്ലീഷിലോ), ഓതറുടെ പേര്, ബാർകോഡ് നമ്പർ, കാറ്റഗറി എന്നിവ വെച്ച് തത്സമയം സെർച്ച് ചെയ്യാം.

4. **സിനിമാറ്റിക് ക്യാമറ ഫ്ലൈ-ത്രൂ & ബുക്ക് ലിഫ്റ്റ് (Camera Walkthrough & Book Floating):**
   - സെർച്ചിൽ നിന്ന് ഏതെങ്കിലും ബുക്കിൽ ക്ലിക്ക് ചെയ്താൽ:
     - വാതിലിൽ നിന്ന് ക്യാമറ ലൈബ്രറി ഇടനാഴിയിലൂടെ സുഗമമായി നീങ്ങുന്നു.
     - ബുക്ക് ഇരിക്കുന്ന പ്രത്യേക ഷെൽഫിലേക്ക് തിരിഞ്ഞ്, കൃത്യം ആ റാക്കിന്റെ മുന്നിൽ ഫോക്കസ് ചെയ്യുന്നു.
     - നിർദ്ദിഷ്ട ബുക്ക് ഷെൽഫിൽ നിന്ന് മുന്നോട്ട് തെന്നിമാറി, മുകളിലേക്ക് ഉയർന്ന്, നിങ്ങളുടെ നേരെ ഫേസ് ചെയ്തു തിരിഞ്ഞു നിൽക്കുന്നു!
     - "തിരികെ വെക്കുക (Put Back)" ക്ലിക്ക് ചെയ്താൽ ബുക്ക് സുഗമമായി തിരികെ ഷെൽഫിലെ അതിന്റെ സ്ഥാനത്തേക്ക് കയറിപ്പോകുന്നു.

---

### 🚀 എങ്ങനെ പ്രവർത്തിപ്പിക്കാം (How to Run)

1. ഫോൾഡറിലുള്ള **`run_library.bat`** ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക.
   - അല്ലെങ്കിൽ ടെർമിനലിൽ `python server.py` റൺ ചെയ്യുക.
2. ബ്രൗസറിൽ തനിയെ **`http://localhost:5051`** തുറന്നുവരും.

---

### 📁 ഫയൽ വിവരങ്ങൾ (File Structure)
- **`library.glb`**: Blender-ൽ നിന്ന് വെബ്ബിനായി എക്സ്പോർട്ട് ചെയ്ത 3D ലൈബ്രറി മോഡൽ.
- **`library_layout.json`**: ഓരോ കാറ്റഗറിയുടെയും ഷെൽഫ് കോർഡിനേറ്റുകളും റാക്ക് ലെവലുകളും.
- **`books.json`**: ലൈബ്രറിയിലെ പുസ്തകങ്ങളുടെ ഡാറ്റാബേസ്.
- **`app.js`**: Three.js, GSAP ക്യാമറ ആനിമേഷൻ, പ്രൊസീജറൽ ബുക്ക് ടെക്സ്ചർ ലോജിക്.
- **`styles.css`**: ഡാർക്ക്-മോഡ് ഗ്ലാസ്മോർഫിക് ഡിസൈൻ.
- **`index.html`**: പ്രധാന വെബ് ഇന്റർഫേസ്.
- **`server.py`**: Python ബാക്കെൻഡ് സെർവർ & API.
